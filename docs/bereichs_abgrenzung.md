# Bereichs-Abgrenzung (Zuordnungs-Matrix)

> **Stand: 2026-06-20.** Verbindliche Referenz für die Zuordnung von Konzepten zu
> Hauptbereichen. Maßgeblich **bevor** neue Inhalts-Wellen gesammelt werden und bevor die
> geplanten Bereiche **Machina** und **Historia** gebaut werden. Ergänzt die Inhaltsregeln in
> `AGENTS.md` (u. a. den globalen **Politik-Ausschluss**).

## Warum diese Datei

Mit **Machina** (Digital/IT) und **Historia** (Geschichte) entstehen Überschneidungen zu
bestehenden Bereichen — Technikgeschichte, Kunst-/Bauepochen, Wissenschaftsgeschichte und
Entdecker lassen sich auf mehrere Bereiche ziehen. Ohne klare Trennlinie landet dasselbe
Wissen doppelt (zwei Konzepte, kollidierende Distraktor-Pools) oder gar nicht. Diese Matrix
legt für jeden Grenzfall **einen Primär-Owner** fest.

## Leitprinzip: Ordnungsachse statt Thema

Jeder Bereich hat **eine primäre Ordnungsachse**. Ein Konzept gehört in den Bereich, dessen
Achse die **Quizfrage trägt** — nicht in jeden Bereich, dessen Thema es nebenbei berührt.

| Bereich  | Ordnungsachse | Kernfrage |
|----------|---------------|-----------|
| **Terra**    | Ort auf der Erde            | *Wo liegt …?* |
| **Astra**    | Himmelskörper / Kosmos     | *Welches Objekt jenseits der Erde …?* |
| **Natura**   | Organismen + unbelebte Erdnatur | *Welches Lebewesen / Gestein / Naturphänomen …?* |
| **Homo**     | Menschlicher Körper        | *Welcher Körperteil / physiologische Eckwert …?* |
| **Cultura**  | Vom Menschen geschaffenes Werk / Artefakt | *Welches Kunst-/Bau-/Musik-/Literaturwerk …?* |
| **Lingua**   | Sprache als System         | *Welche Sprache / Schrift / Wortherkunft …?* |
| **Machina**  | Technik / Digitales als Funktionsprinzip | *Wie funktioniert … / was leistet …?* |
| **Historia** | Zeit / Ereignis / Urheberschaft | *Wann / durch wen / in welcher Epoche …?* |

**Objekt-vs-Zeit-Regel (die zentrale Trennlinie):** Die sechs Sach-Bereiche
(Terra/Astra/Natura/Homo/Cultura/Lingua) + Machina besitzen jeweils **das Objekt**. **Historia
besitzt den datierbaren Verlauf** — Datierung, Chronologie, Urheberschaft, Epochen-Einordnung.
Ein und dieselbe Sache kann deshalb in zwei Bereichen je **eine andere, eindeutige** Frage
erzeugen (das ist erwünschte Quervernetzung), aber das **Konzept** wird nur in **einem**
Bereich geführt (Primär-Owner, siehe Matrix).

## Kern-Scope je Bereich + was bewusst draußen bleibt

| Bereich | Gehört rein | Gehört NICHT rein (→ wohin) |
|---------|-------------|------------------------------|
| **Terra** | Länder, Städte, Provinzen, Flüsse, Seen, Gebirge als **Orte/Karte**; politisch-administrative Geografie | Geologie eines Gesteins → Natura · Klima als Phänomen → Natura · Entstehungsgeschichte eines Staates → Historia |
| **Astra** | Planeten, Monde, Sterne, Galaxien, Schwarze Löcher, kosmische Konstanten | Entdeckungsgeschichte/Astronom → Historia · Teleskop als Gerät → Machina |
| **Natura** | Tiere, Pflanzen, Pilze, Lebensräume/Biome, Gesteine, Mineralien, Naturphänomene, Klima (IPCC-Konsens) | Menschlicher Körper → Homo · Domestikations-/Entdeckungsgeschichte → Historia |
| **Homo** | Knochen, Muskeln, Organe, physiologische Eckwerte, menschliche Arten | **Keine Krankheiten**, **keine Kultur** (gilt schon) · Medizingeschichte → Historia |
| **Cultura** | Konkrete Kunst-, Skulptur-, Architektur-, Musik- und Literaturwerke + ihre Stilmerkmale; Zitate | Epoche als **Zeitabschnitt** → Historia · Literatursprache/Etymologie → Lingua |
| **Lingua** | Sprachen, Sprachfamilien, Schriftsysteme, Wortherkünfte/Etymologie | Literarisches Werk → Cultura · datierte Schrift-Meilensteine → Historia |
| **Machina** | Funktionsprinzip von Computern, Netzen, Geräten, Verfahren, Algorithmen | **Erfindungsdatum/-person/-reihenfolge** → Historia |
| **Historia** | Datierbare Ereignisse, Chronologien, Urheberschaft, Epochen, Entdeckungen/Erfindungen als **Zeit-Fakt** | Funktions-/Merkmalsfragen zum Objekt → jeweiliger Sach-Bereich · **Tages-/Gegenwartspolitik & -ismen-Wertungen → ganz raus** |

## Grenzfall-Matrix (Entscheidungen)

| Grenzfall | Primär-Owner | Trennlinie / Faustregel |
|-----------|--------------|--------------------------|
| **Technikgeschichte** (Dampfmaschine, Transistor, Internet) | **Machina** = Funktionsprinzip; **Historia** = Erfindungsdatum/-person/-chronologie | *Wie funktioniert es / was leistet es* → Machina. *Wann, von wem, in welcher Reihenfolge* → Historia. |
| **Kunst- & Bauepochen** (Gotik, Barock, Bauhaus) | **Cultura** = das Einzelwerk + seine Stilmerkmale; **Historia** = die Epoche als datierter Zeitabschnitt | Konkretes Werk/Merkmal → Cultura. „Welche Epoche dauerte 1000–1250 / kam vor X?" → Historia. |
| **Wissenschaftsgeschichte / Entdecker** (Schwarzes Loch, Tierart, Element) | **Astra/Natura/Homo** = das Objekt/der Befund; **Historia** = die Entdeckungsgeschichte | Eigenschaft des Objekts → Sach-Bereich. „Wer entdeckte wann?" → Historia. |
| **Medizingeschichte** (Impfung, Anatomie-Pioniere) | **Homo** = anatomisch-physiologisches Objekt; **Historia** = Datierung/Person | Homo bleibt körperlich (keine Krankheiten, keine Kultur). Historischer Meilenstein → Historia. |
| **Schrift- & Sprachgeschichte** (Alphabet, Buchdruck-Wirkung auf Sprache) | **Lingua** = System/Etymologie; **Historia** = datierte Meilensteine | Sprachsystem/Wortherkunft → Lingua. „Wann entstand … / wer schuf …" → Historia. |
| **Physische Geografie** (Fluss, Gebirge, Vulkan) | **Terra** = Ort/Karte; **Natura** = Naturphänomen/Geologie | Als verortbares Geo-Objekt (Karte) → Terra. Als Gestein/geologischer Prozess/Biom → Natura. |
| **Geräte für Wissenschaft** (Teleskop, Mikroskop) | **Machina** = das Gerät; Sach-Bereich = das damit untersuchte Objekt | Das Instrument selbst → Machina. Was es zeigt (Stern/Zelle) → Astra/Natura. |
| **Literarisches Werk vs. Sprache** | **Cultura** = das Werk; **Lingua** = die Sprache des Werks | Roman/Gedicht/Autor → Cultura. Grammatik/Etymologie der Sprache → Lingua. |

## Meta-Regeln

1. **Historia ist kein Sammelbecken.** Ein Konzept landet nur dann in Historia, wenn die
   **Zeit-/Ereignis-Dimension** das eigentliche Quizziel ist (Datierung, Chronologie,
   Urheberschaft als historisches Faktum) und kein Sach-Bereich das Objekt schon trägt. Bei
   Doppelqualifikation gewinnt der **spezifischere Sach-Bereich** das Objekt; Historia bekommt
   höchstens die separate Zeit-Frage.
2. **Ein Konzept = ein Primär-Owner.** Quervernetzung (dieselbe Sache erzeugt in zwei
   Bereichen je eine andere Frage) ist erlaubt, aber die Konzept-Datenbasis liegt in genau
   einem Bereich. Kein Duplikat über Bereiche hinweg.
3. **Im Zweifel: Objekt vor Zeit, Funktion vor Datum, Werk vor Epoche.** Diese drei
   Faustregeln decken die meisten Grenzfälle ab.
4. **Politik-Ausschluss bleibt global** (siehe `AGENTS.md` → Inhaltsregeln): Gegenwarts-/
   Tagespolitik und Wertungs-/-ismen-Debatten bleiben in **allen** Bereichen draußen, schon bei
   der Quellenwahl. Historische Politik nur als nüchterne, datierbare Fakten ohne Wertung.
